## Added

- You can now create, edit, and delete test suites to group existing test cases together in a specific order.
- Test cases inside a suite can be reordered by dragging and dropping them.
- A search box on the suite page lets you find and add existing test cases to a suite.
- Deleting a test case now warns you how many test suites will be affected before you confirm.

## Fixed

- Status and feature labels now show up capitalized everywhere, instead of a mix of lowercase and capitalized text.
- The search box on the suite page no longer cuts off its placeholder text.
- The case list inside a suite now uses a proper table layout, so the severity badge, status, and remove button all line up correctly.
- The new/edit test case and new/edit suite pop-up forms can now be closed with the Escape key, keep keyboard focus inside the form while open, and are read out correctly by screen readers.

## Known issues

- Editing a test case through a direct API call (bypassing the form) can currently save a blank title or blank expected result.
- The sortable column headers on the test case list only work with a mouse, not a keyboard.
