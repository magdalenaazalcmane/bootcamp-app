# Quick search treats a whitespace-only query as empty [Quick Search]

## Preconditions

None.

## Steps

1. Open quick search.
2. Type three spaces into the search field and nothing else.

## Expected result

The modal behaves as if the field were empty: it shows "Start typing to search across the app.", no results are fetched, and no "No results" message is shown.

## Severity

Minor
