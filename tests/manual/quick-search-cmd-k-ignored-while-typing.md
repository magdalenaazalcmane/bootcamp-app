# Cmd+K does not open quick search while a text field is focused [Quick Search]

## Preconditions

User is on a page with a text input or textarea, e.g. creating or editing a test case.

## Steps

1. Click into a text input or textarea on the page so it has focus.
2. Press Cmd+K (or Ctrl+K).

## Expected result

The quick search modal does not open. The keystroke has no effect on the app; typing in the focused field is not interrupted.

## Severity

Major
