# Signup accepts a password at the maximum length of 20 characters [Signup]

## Preconditions

The user is on the signup page.

## Steps

1. Enter "newuser@example.com" in the Email field.
2. Enter "validuser1" in the Username field.
3. Enter "Passw0rdPassw0rd1234" (20 characters, contains numbers) in the Password field.
4. Click "Sign up".

## Expected result

The account is created. The 20-character password is accepted.
