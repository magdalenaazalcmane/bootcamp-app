# Quick search returns a single result when only one item matches [Quick Search]

## Preconditions

Exactly one test case exists containing the unique word "Zzyx" in its title. No bug or suite contains that word.

## Steps

1. Open quick search.
2. Type "Zzyx".
3. Wait for the search results to load.

## Expected result

Only the "Test cases" group is shown, containing exactly the one matching test case. The "Bugs" and "Test suites" groups are not rendered.

## Severity

Major
