# Case count column reflects the number of cases in the suite [Test Suites]

## Preconditions

A suite exists with 0 cases.

## Steps

1. Navigate to /test-suites and note the case count for the suite (should be 0).
2. Open the suite and add two test cases to it.
3. Navigate back to /test-suites.

## Expected result

The case count column for the suite now shows 2.

Minor
