# Pressing Enter navigates to the first suite when only suite results exist [Quick Search]

## Preconditions

A search term matches at least one suite and matches no test cases or bugs.

## Steps

1. Open quick search.
2. Type the search term.
3. Wait for the results to load.
4. Press Enter while focus is still in the search field.

## Expected result

The app navigates to the detail page of the first suite result and the quick search modal closes.

## Severity

Minor
