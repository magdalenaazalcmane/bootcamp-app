# Pressing Enter navigates to the first bug when only bug results exist [Quick Search]

## Preconditions

A search term matches at least one bug and matches no test cases or suites.

## Steps

1. Open quick search.
2. Type the search term.
3. Wait for the results to load.
4. Press Enter while focus is still in the search field.

## Expected result

The app navigates to the detail page of the first (topmost) bug result and the quick search modal closes.

## Severity

Minor
