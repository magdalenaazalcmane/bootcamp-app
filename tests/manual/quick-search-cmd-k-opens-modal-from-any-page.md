# Cmd+K opens quick search from any page in the app [Quick Search]

## Preconditions

No text field is focused.

## Steps

1. Navigate to each of the Dashboard, Test Cases, Bugs, Test Runs, Reports, and Settings pages in turn.
2. On each page, press Cmd+K.

## Expected result

The quick search modal opens on every page, with the search input focused and empty.

## Severity

Major
