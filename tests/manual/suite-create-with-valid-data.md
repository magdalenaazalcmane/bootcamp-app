# User can create a new test suite with valid name and feature [Test Suites]

## Preconditions

The user is on the /test-suites page.

## Steps

1. Click "+ New suite".
2. Enter "Checkout regression suite" in the Name field.
3. Enter "checkout" in the Feature field.
4. Leave Status as "Draft".
5. Click "Save".

## Expected result

The modal closes, and the new suite appears in the list with name "Checkout regression suite", feature "checkout", status "Draft", and case count 0.

## Severity

Major

## Status

draft
