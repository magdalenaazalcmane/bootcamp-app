# Removing a case from a suite happens immediately without confirmation [Test Suites]

## Preconditions

A suite contains at least one case.

## Steps

1. Open the suite's detail page.
2. Click "Remove" on a case row.

## Expected result

The case is removed from the table immediately, with no confirmation dialog shown, and the case count decreases by 1.

## Severity

Minor
