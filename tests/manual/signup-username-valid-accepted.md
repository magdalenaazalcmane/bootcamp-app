# User can sign up with a valid username [Signup]

## Preconditions

The user is on the signup page.

## Steps

1. Enter "newuser@example.com" in the Email field.
2. Enter "validuser1" (10 characters, no spaces) in the Username field.
3. Enter "Password1" in the Password field.
4. Click "Sign up".

## Expected result

The account is created. The username is accepted.

Major
