# Signup is rejected when password is empty [Signup]

## Preconditions

The user is on the signup page.

## Steps

1. Enter "newuser@example.com" in the Email field.
2. Enter "validuser1" in the Username field.
3. Leave the Password field blank.
4. Click "Sign up".

## Expected result

Signup is rejected with an error stating password is required. No account is created.

## Severity

Major
