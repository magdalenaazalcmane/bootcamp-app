# Reordered case sequence persists after reloading the page [Test Suites]

## Preconditions

A suite's cases were just reordered via drag-and-drop.

## Steps

1. Reorder the cases in a suite.
2. Reload the /test-suites/:id page.

## Expected result

The cases table shows the same order that was set by the reorder action.

## Severity

Major
