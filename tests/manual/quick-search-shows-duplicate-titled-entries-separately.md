# Quick search lists duplicate-titled items as separate results [Quick Search]

## Preconditions

Two different test cases exist with the exact same title, e.g. both titled "Add item to cart".

## Steps

1. Open quick search.
2. Type "Add item to cart".
3. Wait for the search results to load.

## Expected result

Both test cases appear as two separate entries in the "Test cases" group. They are not deduplicated or merged into one entry.

## Severity

Minor
