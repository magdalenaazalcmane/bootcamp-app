# Deleting a suite shows a confirmation dialog naming the suite [Test Suites]

## Preconditions

At least one suite named "Login regression suite" exists.

## Steps

1. Navigate to /test-suites.
2. Click "Delete" on the row for "Login regression suite".

## Expected result

A confirmation dialog appears with the text: Delete "Login regression suite"? This cannot be undone.

## Severity

Major
