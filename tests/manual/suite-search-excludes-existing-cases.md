# Search results exclude cases already in the suite [Test Suites]

## Preconditions

A suite already contains the test case "Login is rejected with an incorrect password".

## Steps

1. Open the suite's detail page.
2. In the "Add a case" search box, type "login".

## Expected result

The search results list does not include "Login is rejected with an incorrect password", since it is already in the suite.

## Severity

Minor
