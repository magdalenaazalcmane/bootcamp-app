# User can filter test suites by status [Test Suites]

## Preconditions

At least two suites exist with different statuses (e.g. one "draft", one "ready").

## Steps

1. Navigate to /test-suites.
2. Open the status filter dropdown.
3. Select "ready".

## Expected result

Only suites with status "ready" are shown in the table.

## Severity

Major

## Status

draft
