# User can view the list of test suites with all columns [Test Suites]

## Preconditions

At least one test suite exists. The user is on the /test-suites page.

## Steps

1. Navigate to /test-suites.
2. Observe the table of suites.

## Expected result

The table shows one row per suite with columns for name, feature, status, case count, and updated date, matching the underlying data.
