# User can add an existing test case to a suite by searching its title [Test Suites]

## Preconditions

A suite exists. A test case titled "User can log in with valid credentials" exists and is not yet in the suite.

## Steps

1. Open the suite's detail page.
2. In the "Add a case" search box, type "log in".
3. Wait for the search results to load.
4. Click "Add" next to "User can log in with valid credentials".

## Expected result

The case appears in the suite's cases table with its title, severity badge, and status. The search box clears, and the case count increases by 1.

## Severity

Major
