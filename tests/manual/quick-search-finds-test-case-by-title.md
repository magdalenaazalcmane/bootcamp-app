# User can find a test case by title using quick search [Quick Search]

## Preconditions

At least one test case exists with a known title, e.g. "Login with valid credentials". User is on any page of the app, with no text field focused.

## Steps

1. Press Cmd+K (or Ctrl+K) to open quick search.
2. Type a word that appears in the known test case's title, e.g. "Login".
3. Wait for the search results to load.

## Expected result

A "Test cases" group appears in the results and includes the matching test case's title.

## Severity

Major
