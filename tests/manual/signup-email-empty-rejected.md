# Signup is rejected when email is empty [Signup]

## Preconditions

The user is on the signup page.

## Steps

1. Leave the Email field blank.
2. Enter "validuser1" in the Username field.
3. Enter "Password1" in the Password field.
4. Click "Sign up".

## Expected result

Signup is rejected with an error stating email is required. No account is created.

## Severity

Major
