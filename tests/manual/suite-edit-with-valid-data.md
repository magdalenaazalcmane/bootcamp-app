# User can edit a suite's name, feature and status [Test Suites]

## Preconditions

A suite exists.

## Steps

1. Open the suite's detail page and click "Edit suite".
2. Change the Name to "Login regression suite v2".
3. Change the Status to "In progress".
4. Click "Save".

## Expected result

The modal closes and the detail page shows the updated name and status "In progress". The change is also reflected on the /test-suites list.

## Severity

Major
