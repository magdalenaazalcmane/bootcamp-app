# User can find a test suite by name using quick search [Quick Search]

## Preconditions

At least one test suite exists with a known name, e.g. "Regression Suite". User is on any page of the app, with no text field focused.

## Steps

1. Press Cmd+K to open quick search.
2. Type a word from the suite's name, e.g. "Regression".
3. Wait for the search results to load.

## Expected result

A "Test suites" group appears in the results and includes the matching suite's name.

## Severity

Major
