# User can sign up with a valid password [Signup]

## Preconditions

The user is on the signup page.

## Steps

1. Enter "newuser@example.com" in the Email field.
2. Enter "validuser1" in the Username field.
3. Enter "Password1" (9 characters, contains a number) in the Password field.
4. Click "Sign up".

## Expected result

The account is created. The password is accepted.

Major
