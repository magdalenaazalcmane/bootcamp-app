# Clearing the search input clears the search results [Test Suites]

## Preconditions

The user has typed a search term in the "Add a case" section and results are visible.

## Steps

1. Clear the search input completely.

## Expected result

The results list and any "Searching…" or "No matching test cases to add." message disappear; nothing is shown below the search box.

Trivial
