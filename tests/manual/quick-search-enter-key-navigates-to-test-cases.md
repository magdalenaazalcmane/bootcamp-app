# Pressing Enter navigates to the test cases list when test case results exist [Quick Search]

## Preconditions

A search term matches at least one test case and at least one bug.

## Steps

1. Open quick search.
2. Type the shared search term.
3. Wait for the results to load.
4. Press Enter while focus is still in the search field.

## Expected result

The app navigates to /test-cases and the quick search modal closes, regardless of the bug results also present.

## Severity

Minor
